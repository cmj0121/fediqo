# 支援

[English](support.md) | [繁體中文](support.zh-TW.md)

> 想最快得到幫助，就開一個把版本寫進去的 issue。

## 去哪裡問

[github.com/cmj0121/fediqo/issues](https://github.com/cmj0121/fediqo/issues)——開一個新的，或補在已經在講
同一件事的那個底下。如果它不該比必要更公開，改寄 <cmj@cmj.tw>。

## 要說什麼

| 告訴我們        | 因為                                                     |
| --------------- | -------------------------------------------------------- |
| 版本與 build    | Mac 上的「關於 Fediqo」，手機上 TestFlight 的 build 頁面 |
| macOS 還是 iOS  | 兩個 app 共用一條時間軸，不共用同一批 bug                |
| 哪一台伺服器    | 協定是一台一台實作的，而伺服器彼此不同                   |
| 你原本預期什麼  | 這裡有一半的回報，最後是意見不同而不是 bug               |

永遠不要寄出 access token、密碼或 Keychain 的內容。我們會問的東西，沒有一樣需要它們。

## 我們幫不上忙的事

Fediqo 講話的對象是它沒有在經營的伺服器。帳號被停權、貼文聯邦不出去、伺服器掛了，都是那台伺服器的事——去問
它的管理員。我們可以幫你判斷是哪一種。

## 常見的答案

**某台伺服器不再交出任何東西。** 它的 token 過期或被收回了。當伺服器不再接受那個帳號時，設定裡那一列的
handle 會轉成橘色；在那裡重新登入一次。

**同一則貼文只出現一次，但它在兩台伺服器上。** 這正是重點——同一則貼文來自好幾個地方就是一列。那一列會說是
哪些伺服器帶它過來的。

**統計說來源之間的比例是估計值。** 確實是。儲存的部分是精確數的；一列合併後的貼文究竟來自哪台伺服器，不是
一個計數能定案的事，所以那個畫面會講清楚哪個數字是哪一種，而不是憑空生一個精確的出來。

**沙盒之前做的 build 看不到我的資料。** macOS app 搬進自己的容器了。沒有任何東西會把舊位置搬過去，原本在那
裡的東西還在 `~/Library/Application Support/`。
