# The first view

[English](first-view.md) | [繁體中文](first-view.zh-TW.md)

> A page opens on what the servers sent. Choices and explanations sit one step in.

Every page a reader lands on shows what a server handed over, and little else. This page is the
rule a page follows to get there: what stays on it, where everything else goes, and what must
never be hidden. A new page follows it without being asked.

## What a first view holds

What the server sent, and the acts used every time that list is read:

| Stays                     | Why                                         |
| ------------------------- | ------------------------------------------- |
| the items, rows and posts | they are what the page is for               |
| open                      | reading a row is the page's own act         |
| reload, and Stop          | asked for every time the list is read       |
| read on, while more can   | the list goes on; a plain end mark when not |
| dismiss one               | done to a single row, where it is read      |

Nothing else stands above or under the list: no paragraph before it, no choice beside it.

## Where a choice goes

A choice has three homes, by what it changes.

| The choice changes               | It goes                                       |
| -------------------------------- | --------------------------------------------- |
| only this page, kept here        | behind a gear on that page                    |
| one source, written to it or kept per host | behind the gear on that source's page |
| every page alike                 | in Preferences                                |

- **The gear is lit while the page is narrowed**, and says so to a listener, so a short list
  is never read as the servers sending little.
- **A single page's filter never becomes a Preferences tab of its own.** If only one page uses
  it, it lives on that page.
- **What a source does not have is absent, not dim.** A source with none of the choices has no
  gear.

## What explains itself

A sentence that only says what a page or a group is becomes a (?) beside its title. The title
names the page; the (?) holds the explanation for the reader who asks.

## The status mark

Trouble and state that belong to a source — not asked, refused, locked, stopped, full at what this
device keeps, nothing more to read — gather into one mark in the page's head: an icon with the
number of sources that need the reader. Pressing it opens a small list of each source, its state
in a sentence, and its Ask or Again.

- It counts a line the reader can act on, or one whose source is missing from the page. A line
  that only informs is listed and not counted; with only such lines the mark is quiet and has no
  number.
- With every source well, there is no mark.

## What always stays

Hiding any of these would make the page lie, so they stay where the reader is:

- an error, and a lock whose press asks for what is missing
- unread, and the empty and signed-out states
- the latest-date sentence, where the stream is cut short
- the line where Home and its source disagree, with its two presses
- the marks on a post
- the warning that a server can read direct messages
- a read-on press, while more can be read
- the one instruction on an empty Add page
