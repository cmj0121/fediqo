# 隱私

[English](privacy.md) | [繁體中文](privacy.zh-TW.md)

> Fediqo 不蒐集任何東西。沒有 Fediqo 伺服器，也就沒有地方可以蒐集。

這是 App Store 連過來的那份政策。它描述的是這個 repository 裡的 app，而那是唯一存在的 Fediqo——它宣稱的每
一件事，都可以靠建置它所描述的原始碼來查證。

## 我們蒐集什麼

沒有。

沒有我們這邊的帳號，沒有分析、沒有當機回報、沒有廣告識別碼，沒有任何第三方 SDK。這個 app 只有一個外部相依
套件 [GRDB](https://github.com/groue/GRDB.swift)，而它是一個從不離開裝置的 SQLite 函式庫。

## 什麼東西會離開你的裝置，去了哪裡

只去你選的伺服器，而且只因為你開口要：

| 什麼時候        | 送出什麼                       | 送到哪裡                       |
| --------------- | ------------------------------ | ------------------------------ |
| 你登入時        | app 註冊與 OAuth 交換          | 你指名的伺服器，經過你的瀏覽器 |
| 你讀時間軸時    | 要貼文的請求，帶著你的 token   | 你加進來的那些伺服器           |
| 貼文帶著媒體時  | 要那張圖或那段影片的請求       | 那台伺服器放媒體的地方         |
| 你發文、回覆、轉推時 | 你寫的內容，每個你選的網路各一次 | 你選的那些伺服器            |

沒有任何東西被轉送。上面每一條線的中間都沒有 Fediqo 伺服器，而這就是隱私宣稱的全部——不多，也不少。請求一
旦抵達你加進來的伺服器，之後由那台伺服器自己的政策管，我們不是其中一方。

## 什麼東西留在你的裝置上

你的 access token 在系統 Keychain 裡。其餘的一切——你讀過的貼文、你留下的東西、你加的伺服器、你的設定——都在
app 自己容器裡的一個 SQLite 資料庫，就在 app 旁邊。趨勢與摘要是從那個資料庫算出來的，在你的裝置上。

刪掉 app 就一起刪掉那個資料庫。Token 可以在發出它的伺服器上撤銷。

## 兒童

Fediqo 不以兒童為對象，也不詢問年齡、姓名或任何身分。

## 變更

這份檔案跟著 app 一起版本控制。一次發行被告知要說什麼，就是這份檔案在那個 tag 上說的話。
