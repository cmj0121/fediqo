# 第一眼

[English](first-view.md) | [繁體中文](first-view.zh-TW.md)

> 頁面打開時是伺服器送來的東西。選擇與說明在往裡一步的地方。

讀者落到的每一頁，呈現伺服器交來的東西，其他的很少。這一頁寫的是頁面怎麼做到這一點的規則：什麼留在頁面上、其他的去哪裡，以及什麼絕不能藏起來。新的頁面不用人提醒，就照著它做。

## 第一眼有什麼

伺服器送來的東西，加上每次讀那份清單都會用到的動作：

| 留下                 | 為什麼                                   |
| -------------------- | ---------------------------------------- |
| 項目、列、貼文       | 頁面就是為了它們                         |
| 打開                 | 讀一列是這頁自己的動作                   |
| 重新載入，與停止     | 每次讀這份清單都會要                     |
| 往下讀，在還有的時候 | 清單還沒完；沒有更多時是一個單純的結尾記號 |
| 移除一則             | 對單一列做的事，就在讀它的地方           |

清單的上方與下方不放別的：前面沒有段落，旁邊沒有選擇。

## 選擇放哪裡

選擇依它改變什麼，有三個家。

| 這個選擇改變的            | 它放在                       |
| ------------------------- | ---------------------------- |
| 只有這一頁，留在這裡      | 那一頁的齒輪後面             |
| 一個來源，寫回它或依主機留 | 那個來源頁面的齒輪後面       |
| 每一頁都一樣              | 偏好設定                     |

- **頁面被縮減時齒輪會亮起**，也會告訴聆聽的人，所以一份短的清單不會被讀成伺服器送得少。
- **單一頁面的篩選絕不會變成偏好設定裡自己的一個分頁。** 只有一頁用到，就留在那一頁。
- **來源沒有的東西就不出現，不是變暗。** 一個什麼選擇都沒有的來源，就沒有齒輪。

## 會自己說明的

只是說明一頁或一組是什麼的句子，變成標題旁的 (?)。標題說出頁面的名字；(?) 為問的讀者留著說明。

## 狀態記號

屬於某個來源的麻煩與狀態——沒問過、被拒絕、被鎖住、停下、到了這台裝置保留的上限、沒有更多可讀——集中成頁首的一個記號：一個圖示，加上需要讀者處理的來源數。按下它會打開一份小清單，列出每個來源、一句話的狀態，以及它的「詢問」或「再試」。

- 讀者能處理的一行，或來源從頁面上缺了東西的一行，會被計數。只是告知的一行會列出但不計數；只有這種行時，記號是安靜的，沒有數字。
- 每個來源都好好的時候，就沒有記號。

## 永遠留著的

把這些藏起來會讓頁面說謊，所以它們留在讀者所在的地方：

- 錯誤，以及按下會請求缺少權限的鎖
- 未讀，以及空的、未登入的狀態
- 串流被截短時，最新日期的那句話
- 首頁與它的來源不一致的那一行，與它的兩個按鈕
- 貼文上的記號
- 伺服器能讀私訊的警告
- 還有更多可讀時，往下讀的按鈕
- 空的「新增」頁上唯一的那句說明

## 它改了哪些頁

| 頁面       | 移動了什麼                                                 |
| ---------- | ---------------------------------------------------------- |
| 通知       | 每個來源的句子收進狀態記號；清單的結尾成為單純的記號       |
| 通知       | 顯示的種類放到會亮的齒輪後面                               |
| 通知       | 來源擋下的通知成為一列，打開是它自己的一頁                 |
| 來源       | 它擋下誰的通知，從通知頁移到來源的設定                     |
| 來源       | 即時串流、它告知的通知、擋下的設定與篩選放到它的齒輪後面   |
| 目錄       | 它的排序與只看本站的選擇放到齒輪後面                       |
| 偏好設定   | 一個選擇在這台裝置上關掉每個來源的篩選                     |
| 清單、趨勢 | 頁尾解釋的句子拿掉了                                       |
| 說明文字   | 頁面的說明成為 (?)；搜尋缺少的來源放進狀態記號             |
| 時間軸     | 寬的頁首不再把規則寫出來                                   |
